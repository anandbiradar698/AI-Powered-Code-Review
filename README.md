# AI-Powered-Code-Review
An AI-powered code analysis application that uses an Ollama model to detect bugs, identify performance issues, and provide code improvement suggestions.
<hr>
✨ Features
🔍 Detects bugs and edge cases
⚡ Highlights performance issues
💡 Suggests improvements
📊 Provides structured feedback (Summary, Bugs, Performance, Improvements, Rating)
🧠 Supports multiple languages (Java, Python, JavaScript, etc.)
